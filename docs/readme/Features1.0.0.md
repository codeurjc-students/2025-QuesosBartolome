## Features – Version 1.0.0

Below is a detailed overview of the features included in version 1.0.0 of the website:

![Main Screen](/Images/MainPageUR.png)

- On this screen you can see the main page for a registered user, with the new cheese pagination (now 5 per page instead of 10) and real product images. Additionally, two new sections appear in the navigation bar: orders and invoices.

![Cheese Page](/Images/CheesePageNR.png)

- On the detail page of each cheese, the new images and the newly added reviews can also be seen.

![OrdersPage](/Images/OrdersPageRU.png)

- On this screen, a registered user can view their orders and their status. By clicking on any of them, the user can access a detailed page.

![Order Preview](/Images/OrderPreviewPageRU.png)

- Detailed page of an order as viewed by a registered user.

![InvoicesPage](/Images/InvoicesPageRU.png)

- Screen where a user can view their invoices and download them.

![Clients](/Images/ClientsPage.png)

- On this screen, the new clients added to the database can be seen. They are fictional but located in the cheese production area, providing a more realistic UI. Real clients are not included for privacy reasons.

![Charts1](/Images/Charts1Page.png)

- Within the charts section, an administrator can view two types of charts and filter them. In this case, the chart shows the annual income evolution. When hovering over each point of the line plot, a tooltip appears with detailed information.

![Charts1](/Images/Charts1PageFilter.png)

- Here we can see the same section but filtered by a client using the multi‑selector.

![Charts2](/Images/Charts2Page.png)

- The second chart displays a bar chart comparing income and production per product. There is a fixed area showing the tooltip information for each bar when hovering over them.

![Charts2](/Images/Charts2PageFilter.png)

- Here the same chart is shown but filtered by two clients using the multi‑selector.

![Dialog Custom](/Images/DialogCustomApp.png)

- We added and replaced the default alerts and confirms with a custom dialog styled with the website’s colors.
