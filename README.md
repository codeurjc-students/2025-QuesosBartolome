# 2025-QUESOS BARTOLOMÉ

## Version 1.0
For this final version, the last adjustments for registered users have been completed. Customers now have greater control and tracking of their orders and invoices.

On the other hand, administrators now have access to the new charts section, which is based on cheese sales and production data. This allows them to analyze business performance and the evolution of production more accurately.

Additionally, real images of the cheeses produced in the dairy have been added to the website interface, along with a set of fictional clients from invented stores inspired by the production area. This provides a more coherent, visually appealing environment that remains closely aligned with the real context of the business.

New Features:

- Registered Users: Once logged in, these users have access to a section where all their orders are listed, including both processed and pending ones. From there, they can select any order and view a detailed summary, allowing them to track the full progression of their purchases.

- Administrators: They now have access to the new charts section, where they can view two types of analyses: the annual income evolution and a comparative chart of income and product production. Additionally, they can filter this data by customers, enabling a more personalized and business‑oriented analysis.

With these functionalities, a stable version of the application is now completed, fully capable of meeting the main objectives of the project. This version supports all activities related to the sales and management processes of Quesos Bartolomé.
